Ajaira Thrift · tutorial

Add many products at once, on your phone

📱 ➜ 🛍️

You fill one spreadsheet.
Shopify creates all the products.

Takes about 5 minutes for 20 products
Before you start

You need two things

  1. Google Sheets app (free)
  2. The file ajaira-products-template.csv

The Shopify app cannot import files.
We use the Shopify website in Chrome or Safari instead.

Save the template file to your phone first
